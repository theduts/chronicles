# Planning & Agent Execution Directory

This directory (`.planning/`) serves as the core state, planning, and documentation hub for the project, guided by the Get-Shit-Done (GSD) workflow.

## Overview
- **ROADMAP.md**: High-level phases and objectives.
- **PROJECT.md**: Project description, technical stack, and architecture.
- **STATE.md**: Current phase state and active tasks.
- **phases/**: Detailed plans (`PLAN.md`) and requirements for each phase.
